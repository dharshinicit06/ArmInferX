# ArmInferX Frontend

Web-based dashboard for the ArmInferX Inference Optimization Studio.

Built with **React 18 + Vite 5** (JavaScript).

## Setup

```bash
# Install dependencies
npm install

# Start the dev server (http://localhost:3000)
npm run dev

# Production build (outputs to dist/)
npm run build

# Preview the production build
npm run preview
```

## Optimization Dashboard

`src/optimization/` adds the **Optimization Dashboard** (STEP 12), reachable via
the header nav. It renders the evidence from `results/optimization_report.json`
(generated by `scripts/run_optimization_report.py`).

Data flows through a single loading/mapping layer (`src/optimization/loadReport.js`):

1. It first calls the backend API `GET /optimization/report` (fresh data).
2. If the backend is unreachable, it falls back to the bundled static copy at
   `public/optimization-report.json`.

After regenerating the report, refresh the bundled copy (the script strips
filesystem-path fields so the browser bundle stays path-free, reusing the same
sanitizer as the backend endpoint):

```bash
python ../scripts/_bundle_sanitized_report.py
```

## Structure

| Path            | Purpose                          |
|-----------------|----------------------------------|
| `index.html`    | HTML entry point                 |
| `src/main.jsx`  | React entry point                |
| `src/App.jsx`   | Landing page + view navigation   |
| `src/optimization/` | Optimization dashboard (component + data layer + styles) |
| `src/index.css` | Global styles & design tokens    |
| `public/`       | Static assets (favicon, bundled report copy) |
